# Project Slicing Asik Kelompok 2

Ini adalah project slicing asik kelompok 2. Project ini dibuat menggunakan pure HTML dan tailwind CSS.

## Cara "Download"/Menggunakan Project
1. Clone repository ini dengan `git clone https://github.com/Celxd/ASIK-Slicing.git` (di folder parent dari project kemarin)
2. Buka file `index.html` dengan live server

## Workflow Pengerjaan
1. Sebelum pengerjaan, pergi ke branch main `git switch main`, update branch dengan `git fetch` dan `git pull`, lalu buat branch baru dengan `git switch -c nama_branch` dengan nama branch sesuai dengan apa yang dikerjakan.
2. Setelah selesai, lakukan commit dengan `git add .` dan `git commit -m "pesan commit"`.
3. Push branch ke remote dengan `git push origin nama_branch`.
